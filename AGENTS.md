# Ink Buddy project guidance

This file applies to work in this repository.

- Read `BUSINESS_REQUIREMENTS.md` before planning product behavior or changing user-facing features. Ink Buddy serves stationery questions, product discovery, recommendations, and image-based product search. Users attach images only; do not design user-facing document uploads.
- Treat `FIRST_DRAFT_SUMMARY.md` and `docs/architecture/AI_STRUCTURE.md` as technical drafts. Reconcile them with the business requirements and the actual code before implementation; do not assume proposed modules already exist.
- Keep project-specific skills and agent instructions in this repository. Do not create or modify global Codex skills or agents for this project.
- State assumptions when product catalog, inventory, pricing, or purchase flow details are missing. Do not fabricate product availability or specifications.

# โทนคำตอบ Text RAG

อัปเดต 2026-10-15 ตาม feedback การใช้งานจริง

## หลักการ

- ตอบคำถามล่าสุดก่อน เช่น ถามสีแดง ให้บอกว่าพบสีแดงหรือยังไม่มีข้อมูล ไม่ทวนรายละเอียดของสีน้ำเงินทั้งชุด
- ใช้ภาษาสนทนาสุภาพ กระชับ เช่น “ลองดูตัวเลือกเหล่านี้ครับ” และ “รุ่นนี้มีสีแดงครับ”
- ราคา THB อ่านเป็น “50 บาท / ด้าม” ไม่บังคับสองตำแหน่งทศนิยมเมื่อเป็นจำนวนเต็ม
- ไม่แสดงกระบวนการภายใน เช่น AI เลือกหลักฐาน, snapshot, catalog หรือข้อความระบุลำดับแบบระบบ
- ไม่แปะคำเตือนเรื่องข้อมูลสด/ผลทดสอบซ้ำทุกคำตอบ หากถามของพร้อมส่งโดยตรงและไม่มีข้อมูลยืนยัน จึงบอกว่ายังยืนยันไม่ได้
- ไม่กล่าวอ้างว่ามีสต็อกจริงเพียงเพราะพบสีหรือรุ่นในข้อมูลสินค้า
- แหล่งสินค้า/แหล่งราคา หน่วยและฐานภาษียังอยู่ในการ์ดอ้างอิง ไม่ลบ metadata
- รายละเอียดร้านยาวไม่คัดลอกมาในคำถามสั้นเรื่องสี/ราคา; คำถามแนะนำหรือคุณสมบัติใช้ข้อความหลักฐานสั้นพร้อม “ร้านระบุว่า” เพื่อไม่ยกคำโฆษณาเป็นผลทดสอบ

## ตัวอย่าง

คำถาม: รุ่นนี้มีสีแดงไหม

```text
รุ่นนี้มีสีแดงครับ
• ปากกาหมึกเจล เพนเทล เอ็นเนอร์เจล BL77 สีแดง — 50 บาท / ด้าม
```

คำถาม: ตัวที่สองราคาเท่าไร

```text
ปากกาหมึกเจล เพนเทล เอ็นเนอร์เจล BL77 สีน้ำเงิน — 50 บาท / ด้าม
```

## ขอบเขตเทคนิค

ยังให้ OpenRouter เลือก Product/Evidence IDs และตรวจ output แบบเดิม จากนั้น server เรียบเรียงด้วยภาษาธรรมชาติที่กำหนด ไม่เปิด free-text generation ให้โมเดลแต่งราคา/คุณสมบัติ ไม่มี provider call เพิ่ม ไม่มี migration หรือ API contract ใหม่ และไม่แก้ข้อความที่บันทึกในประวัติเก่าย้อนหลัง

ทดสอบรอบนี้: intent/adapter/rendering 27 ผ่าน, PostgreSQL disposable 68 ผ่าน รวม ranking/ordinal/variants/replay/rollback/concurrency. ไม่ได้เรียก OpenRouter จริงซ้ำในรอบปรับถ้อยคำนี้ เพราะ provider contract เดิมไม่เปลี่ยน

ทดลองหลัง restart: ส่งคำถามใหม่ในแชตเดิม “รุ่นนี้มีสีแดงไหม” หรือสร้างแชตแล้วถามสินค้า → ราคา → สีอื่น ตรวจว่าคำตอบไม่ทวนคำเตือนและราคายังตรงการ์ด ข้อความเก่าจะคงเดิม

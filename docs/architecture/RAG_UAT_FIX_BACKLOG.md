# Text RAG: รายการแก้จากการทดลองใช้งาน

วันที่ 2026-10-14 — สถานะ: implement RAG-UAT-01–11 แล้ว; ผลทดสอบและข้อจำกัดดู Process 7

ราคา NULL 18 รายการมี [ตารางราคาที่ค้นได้](../report/PRODUCT_PRICE_REVIEW_2026-10-14.md) แล้วและผู้ใช้อนุมัติบันทึกทั้งหมดสำหรับ demo: catalog 67 รายการมีราคาแล้ว ตัวเลขใช้ฐานไม่รวม VAT ตามคำขอ แต่ 3 ราคาใหม่และราคาที่มีอยู่เดิมยังไม่ยืนยันภาษีจากต้นทาง ต้องแยกงานเติมราคาจากการแก้ ranking/price intent และไม่ใช้ราคาต่อแพ็คเทียบต่อด้ามโดยเงียบ ๆ

## กติกาที่ผู้ใช้ยืนยัน

เมื่อถามเรื่องราคา เช่น ถูกที่สุด แพงที่สุด เรียงราคา เปรียบเทียบราคา หรือกำหนดงบ ให้ค้น/เลือกเฉพาะสินค้าที่มีราคาพร้อมใช้ใน DB ไม่ใช้ NULL เป็นศูนย์ ไม่เติมราคาจากโมเดล และไม่ใช้ raw prices ที่ยังพักตรวจ

สำหรับงบบาทต้องใช้ราคา THB; ไม่เปรียบเทียบข้ามสกุลเงินโดยไม่มี conversion ที่ตกลง หน่วยขาย/แพ็กที่เปรียบเทียบไม่ได้ต้องแจ้ง ไม่อนุมานราคาต่อชิ้นเอง

## สิ่งที่พบจากภาพผู้ใช้

- คำถาม “ปากกาน้ำเงิน มีรุ่นไหนบ้าง” มีปากกา Uni สีม่วงติดมา ผลค้นยังไม่คุมสีตามความต้องการอย่างเหมาะสม
- คำถามต่อ “ขอสามรุ่นที่ถูกที่สุด” ถูกขอให้ระบุสินค้าใหม่ แสดงว่าการค้นยังไม่ใช้บริบทก่อนหน้า
- คำถาม “ปากกาน้ำเงิน สามรุ่นถูกที่สุด และ มีสีอื่นไหม” คืน 5 รายการ มีหลายรายการไม่มีราคา และมีสินค้าสีแดงอยู่ในคำตอบหลักโดยไม่แยกเป็นตัวเลือกสีอื่น

ภาพยืนยันผลที่ผู้ใช้เห็น ไม่ได้ยืนยันว่ารายการที่มีคำว่า “สี...” หมายถึงสีหมึกหรือสีด้ามทุกชิ้น ต้องตรวจข้อมูลสินค้าอีกครั้งก่อนกำหนดเงื่อนไข

| ID | Priority | งานแก้ | เกณฑ์รับงาน |
|---|---|---|---|
| RAG-UAT-01 | P1 | Resolve คำถามต่อเนื่องจากแชตเดียวกันก่อน retrieval | “ขอสามรุ่นที่ถูกที่สุด” สืบประเภท/สีจากบริบทได้ ไม่หยิบประวัติแชตอื่น |
| RAG-UAT-02 | P1 | ตรวจ price intent แม้ไม่มีตัวเลขงบ | ถูกที่สุด/แพงที่สุด/เรียงราคา ต้องตัดสินค้าที่ราคาขาดก่อนจัดอันดับ |

| RAG-UAT-04 | P1 | แยกสีหมึก สีด้าม และข้อมูลสีที่กำกวม | ขอหมึกน้ำเงินไม่เลือกหมึกสีม่วง; ถ้าข้อมูลไม่พอให้แจ้งหรือถามเพิ่ม ไม่อนุมาน |
| RAG-UAT-05 | P1 | แยกหลาย intent ในคำถามเดียว | ตอบรายการสีน้ำเงินที่มีราคาก่อน แล้วแยกเรื่องสีอื่นพร้อมหลักฐาน ไม่เอาสีอื่นมาปะปนใน ranking หลัก |
| RAG-UAT-06 | P1 | กำหนดขอบเขต ranking ให้ชัด | “จากที่แนะนำเมื่อกี้” ใช้ชุดนั้น; “ทั้งหมดใน catalog” ค้นชุดใหม่; เมื่อกำกวมให้ระบุขอบเขตที่ใช้หรือถามเพิ่ม |
| RAG-UAT-07 | P2 | Resolve “ตัวที่สอง/รุ่นนี้” ตามลำดับที่แสดงจริง | อ้างสินค้าตามลำดับคำตอบก่อนหน้า ไม่ใช้ลำดับ retrieval ที่ผู้ใช้ไม่ได้เห็น |
| RAG-UAT-08 | P2 | ค้นสีอื่นจากรุ่น/ตระกูลเดียวกัน | ไม่ถือว่าเครื่องเขียนประเภทเดียวกันเป็นสีอื่นของรุ่นเดิม ถ้าไม่มีหลักฐาน variant ให้แจ้งว่ายืนยันไม่ได้ |
| RAG-UAT-09 | P2 | ปรับข้อความเมื่อผลมีไม่ครบจำนวน | พบสินค้าที่มีราคาเพียง 1–2 รุ่น ให้คืนเท่าที่พบพร้อมแจ้ง ไม่เติมสินค้าหรือราคาสมมติ |
| RAG-UAT-10 | P2 | แสดงที่มาคำตอบอ่านง่าย | เว้นระยะ “Ink Buddy” กับป้าย AI/กฎระบบ ซึ่งปัจจุบันดูติดกันในภาพ |

การตีความ “ปากกาน้ำเงิน” ยังไม่ถือว่าผู้ใช้ระบุสีหมึกชัดทุกครั้ง ควรพิจารณาบริบทหรือขอแยกสีหมึก/สีด้าม หากข้อมูลไม่พอ เรื่องราคาต่อชิ้นเทียบต่อแพ็กต้องตรวจหน่วย ไม่ขยายระบบซื้อสินค้า

## เคสให้ทดลองหลังแก้

| ID | วิธีถาม | ผลที่ต้องการหลังแก้ |
|---|---|---|
| T01 | แชตใหม่: “ปากกาหมึกน้ำเงิน สามรุ่นที่ถูกที่สุด” | ไม่เกิน 3 รุ่น หมึกน้ำเงิน มีราคา เรียงถูกไปแพง |
| T02 | “ปากกาหมึกน้ำเงิน มีรุ่นไหนบ้าง” → “จากที่แนะนำเมื่อกี้ ขอสามรุ่นที่ถูกที่สุด” | ใช้บริบทและชุดที่แสดงก่อนหน้า เลือกเฉพาะรายการมีราคา |
| T03 | “ปากกาหมึกน้ำเงิน สามรุ่นถูกที่สุด และมีสีอื่นไหม” | แยกรายการหลักกับคำตอบเรื่องสีอื่น ไม่คืน 5 รุ่นหรือปะปนสีแดง |
| T04 | “ปากกาหมึกน้ำเงิน สามรุ่นที่แพงที่สุด” | เฉพาะรายการมีราคา เรียงแพงไปถูก |
| T05 | “ปากกาหมึกน้ำเงิน ไม่เกิน 20 บาท ขอ 3 รุ่น” | ไม่เกินงบ; ถ้าพบไม่ครบ 3 ให้แจ้งจำนวนจริง |
| T06 | หลังมีรายการ: “ตัวที่สองราคาเท่าไร” | อ้างตัวที่สองที่แสดงจริง ถ้าราคาขาดแจ้งตามจริง |
| T07 | “รุ่นนั้นมีสีแดงไหม” | ค้น variant ของรุ่นที่อ้าง ถ้ากำกวมหรือไม่มีข้อมูลให้ถาม/แจ้ง |
| T08 | “ปากกาหมึกน้ำเงิน ด้ามสีส้ม” | แยกเงื่อนไขหมึกกับด้าม ไม่ใช้สีส้มแทนสีหมึก |
| T09 | “เอารุ่นถูกที่สุดทั้งหมดใน catalog แทนรายการเมื่อกี้” | เปลี่ยนขอบเขตตามที่ระบุ ไม่จำกัดชุดเก่าโดยเงียบ ๆ |
| T10 | คุยปากกา → “เปลี่ยนเป็นสมุด ไม่เกิน 50 บาท” | เปลี่ยนหัวข้อ ไม่สืบสี/ยี่ห้อปากกาไปสมุดเอง |
| T11 | เปิดแชตใหม่ → “ขอสามรุ่นที่ถูกที่สุด” | ขอประเภทสินค้า ไม่ใช้บริบทจากแชตเก่า |
| T12 | “รุ่นราคาถูกที่สุดมีของพร้อมส่งไหม” | ไม่ยืนยันว่าสต็อกสด/พร้อมส่งจากราคาอย่างเดียว แจ้งข้อจำกัด catalog |

เคสเหล่านี้เป็น manual UAT หลังแก้ ให้เก็บทุกผลที่พบ ไม่ต้องยิงซ้ำจนกว่าจะได้คำตอบที่ถูก คำถามปกติไม่เกี่ยวราคาอาจยังแสดงสินค้าราคาขาดได้โดยแจ้งตามจริง

## สิ่งที่ต้องคงไว้เมื่อ implement

- Rewriting/intent resolution รับเฉพาะประวัติแชตที่ผ่าน ownership และข้อมูลจำเป็น ไม่มี token/password/account data
- Intent/schema เป็นค่าที่ตรวจได้ ไม่รับ SQL/ราคา/URL ที่โมเดลสร้าง; ราคาและ ranking มาจาก DB
- คง input/output guardrails, atomic User/Assistant history, credential/ownership recheck หลังเรียก AI และ request replay
- Provider/output failure ไม่บันทึกคู่ข้อความ คงร่าง ไม่มี fallback/retry อัตโนมัติ
- ทดสอบ query เปลี่ยนหัวข้อ, ambiguity, replay, concurrent send และ claim/logout/delete ระหว่างตอบ

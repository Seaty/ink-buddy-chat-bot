# แบบตรวจคุณภาพคำตอบ RAG โดยทีม

สถานะ: ยังไม่ประเมิน — ห้ามใส่คะแนนแทนผู้ประเมิน

เตรียมคำถามและคำตอบจริงจากรอบ acceptance ไว้ใน [หลักฐานให้ทีมตรวจ](../report/RAG_ACCEPTANCE_frozen_HUMAN_REVIEW.md) ทั้ง 12 ข้อ คะแนนด้านล่างยังว่างตามเดิม

มี [ข้อสังเกตจากผู้ช่วยและผลตรวจ catalog](RAG_ANSWER_REVIEW_PROCESS.md) แยกไว้แล้ว ใช้เป็นข้อมูลประกอบได้ แต่ไม่ใช่คะแนนมนุษย์หรือผลประเมินอิสระ

เลือกคำถามใหม่จากการใช้งานจริง หลีกเลี่ยงการใช้ข้อเดียวกับชุดที่ปรับระบบ บันทึกวันที่ ผู้ประเมิน เวอร์ชันโค้ด model และ catalog ที่ใช้ คะแนน 0 = ไม่ผ่าน, 1 = บางส่วน, 2 = ผ่าน; N/A เมื่อหัวข้อนั้นใช้ไม่ได้

| หัวข้อ | ตรวจอะไร |
|---|---|
| ความตรงคำถาม | หมวด ยี่ห้อ รุ่น สี วัสดุ และงบตรงคำถามหรือไม่ |
| ข้อเท็จจริง | ชื่อ ราคา หน่วย และคุณสมบัติตรงข้อมูลต้นทาง ไม่มีข้อกล่าวอ้างที่แต่งขึ้น |
| หลักฐาน | เหตุผลที่เลือกมาจากสินค้านั้นจริง และเกี่ยวข้องกับความต้องการ |
| ที่มา | product_refs เปิดตรวจได้ หรือแจ้งว่าไม่มี source อย่างชัดเจน |
| ความเข้าใจง่าย | ภาษาไทยและข้อจำกัดอ่านเข้าใจ เหตุผลหนึ่งข้อเพียงพอหรือไม่ |

# Chat UI — Loading, progressive answer and product cards

วันที่ 2026-10-15 · branch feature/chat-ui

## สิ่งที่เปลี่ยน

- ส่งคำถามแล้วแสดงข้อความผู้ใช้ทันที พร้อมจุดเคลื่อนไหวและสถานะระหว่างรอ API
- คำตอบใหม่ค่อย ๆ แสดงเป็นคำ รองรับภาษาไทยด้วย Intl.Segmenter ไม่ตัดสระ/วรรณยุกต์ด้วยการ slice ตัวอักษรเอง
- มี cursor ระหว่างแสดง และปุ่ม “แสดงคำตอบทั้งหมด” เพื่อข้ามเอฟเฟกต์
- การ์ดสินค้าปรากฏหลังข้อความครบ แสดงลำดับตาม product_refs เดิม ชื่อ/ราคาเด่น หน่วยและสีเป็นกลุ่มย่อย
- สีอื่นอยู่ภายในกล่องของรุ่นนั้น แหล่งสินค้า/แหล่งราคาแยกชัด รายละเอียด SKU/ฐานภาษีพับได้ ไม่ลบข้อจำกัดข้อมูล
- คงสีพื้นขาว/เทาและน้ำเงินเดิม; มือถือเรียงการ์ดหนึ่งคอลัมน์ แท็บเล็ต/เดสก์ท็อปสองคอลัมน์
- ข้อความเพิ่มแล้วเลื่อนตามอัตโนมัติ เลื่อนขึ้นด้วยเมาส์ สัมผัส หรือคีย์บอร์ดจะพักการตาม มีปุ่มกลับไปข้อความล่าสุด
- เปิดประวัติหรือ reload แสดงข้อความทันที ไม่เล่นเอฟเฟกต์ย้อนหลัง; reduced-motion แสดงคำตอบทันทีและปิดแอนิเมชันตกแต่ง

## การทำงาน

```text
Send → pending user bubble + loading status
     → POST ส่งกลับ User/Assistant ที่บันทึกแล้ว
     → progressive text → product cards
     → ResizeObserver เลื่อนตาม ถ้าผู้อ่านยังติดตามข้อความล่าสุด
```

นี่เป็นเอฟเฟกต์การแสดงผลหลัง REST API ส่งคำตอบครบ ไม่ใช่ streaming tokens จากโมเดล ไม่มี endpoint/DB/provider contract ใหม่ ไม่เรียก AI เพิ่ม และไม่แก้ประวัติที่บันทึก

เก็บเพียง ID/timestamp ของคำตอบใหม่ใน memory สูงสุด 100 รายการเพื่อให้เอฟเฟกต์ต่อเนื่องเมื่อเปลี่ยนจากหน้าเริ่มต้นเข้า session ไม่เก็บข้อความใน localStorage และไม่ส่ง mutation ซ้ำเพราะแอนิเมชัน

แยกส่วนไว้ใน assistant-message.tsx, use-chat-scroll.ts และ product-reference.tsx; สี/ระยะ/animation อยู่ globals.css. หลังส่งสำเร็จ refresh เฉพาะรายการแชต ไม่ reload detail จนขัดจังหวะการแสดงข้อความ

## ลองเอง

1. เปิด http://localhost:3000/chat ส่งคำถามเกี่ยวกับสินค้า
2. ระหว่างรอต้องเห็นข้อความที่ส่งและแอนิเมชันรอ
3. ได้คำตอบแล้วข้อความค่อย ๆ ปรากฏ การ์ดตามมาหลังข้อความครบ
4. ระหว่างแสดงคำตอบยาวให้เลื่อนขึ้นอ่าน หน้าต้องไม่ดึงกลับเอง
5. กด “กลับไปข้อความล่าสุด” แล้วควรกลับมาเลื่อนตาม; กด “แสดงคำตอบทั้งหมด” เพื่อข้ามได้
6. ตรวจสีอื่นใต้รุ่นเดิม และกดรายละเอียดเพิ่มเติมเพื่อดูข้อมูลรอง
7. Reload ประวัติเดิมต้องปรากฏทันที ไม่พิมพ์ใหม่
8. ตั้งระบบลดการเคลื่อนไหว แล้วตรวจว่าคำตอบแสดงทันที

รอบนี้ยังไม่เพิ่ม upload UI หรือเปลี่ยนการทำงานของ Vision

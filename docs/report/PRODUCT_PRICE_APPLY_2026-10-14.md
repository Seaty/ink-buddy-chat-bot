- ราคาเดิม 49 รายการไม่เปลี่ยนจำนวนเงิน ไม่มีการหาร/คูณ VAT หรือหารราคาแพ็คเป็นต่อด้าม

- เก็บ price_source_ref, หน่วยขาย, ประเภทหลักฐาน, ข้อจำกัด variant/ภาษี และการอนุมัติไว้ใน attributes ที่ขึ้นต้น price_

- Backup products ก่อนแก้ไว้ใน `.local/backups/` ตามเส้นทางใน [ผล JSON](PRODUCT_PRICE_APPLY_2026-10-14.json) แล้ว update ใน transaction เดียว

- เปรียบเทียบ source_for ก่อน/หลังภายใน transaction แล้วพบว่าไม่เปลี่ยน metadata ราคาไม่ถูกส่งสร้าง text embedding; audit หลังบันทึกไม่พบ index ขาดหรือ stale ไม่มี provider calls
- Manifest/render/catalog tests 6 passed

การยกฐานราคา demo ไม่ได้ยืนยัน stock ราคาสด ค่าจัดส่ง หรือภาษี/ราคาที่คิดตอนชำระเงินจริง ราคา Radius เป็นต่อแพ็ค 12 ด้าม ไม่ใช่ราคาต่อด้าม ต้องแก้หน่วยในการจัดอันดับตาม backlog ก่อนอ้างว่าสินค้าใดถูกที่สุดต่อชิ้น

## สิ่งที่ต้องทราบเมื่อทดลอง

คำตอบเก่าและ product_refs ใน chat history เป็น snapshot เดิม ไม่ rewrite ย้อนหลัง ส่งคำถามใหม่เพื่อใช้ราคาใหม่

ผลทดสอบ/labels ก่อนเติมราคาเป็นหลักฐานตามข้อมูลรอบเดิม เช่น เคสปากกาเจล 50–100 บาทที่เคยคาด no_match ตอนนี้พบราคาที่เข้าเงื่อนไข ต้องทบทวน expectations กับ catalog ใหม่ก่อนประเมินอีกครั้ง ห้ามแก้รายงาน frozen ให้ดูเหมือนผ่านเวอร์ชันใหม่

ยังไม่แก้ conversational retrieval, price intent/ranking, สีหมึก/ด้าม และ citation ราคาอีกเว็บในรอบนี้ รายการเหล่านี้อยู่ใน [UAT backlog](../architecture/RAG_UAT_FIX_BACKLOG.md) เพื่อแก้รวมตามที่ตกลง แหล่งข้อมูลสินค้าเดิมยังคงไว้และ price_source_ref เก็บแยก แต่ API product_refs ปัจจุบันยังต้องเพิ่มการแสดงแหล่งราคาโดยเฉพาะ

## เครื่องมือ Apply

`python -m scripts.apply_demo_prices --apply` ใช้เฉพาะชุดที่ผู้ใช้อนุมัติรอบนี้ ไม่มีการเปลี่ยนราคาที่มีอยู่และไม่ตรง candidate; ถ้าเกิด conflict จะ abort ไม่ overwrite เงียบ ๆ ไม่ต้องรันซ้ำหลังบันทึกสำเร็จ
